# Architecture Reviewer Memory

- [Co-located sub-component anti-pattern](feedback_colocated_subcomponent_antipattern.md) — Engineers put private JSX-returning helpers inside parent files; flag as one-component-per-file violation
- [Retained file name flag](feedback_retained_name_flag.md) — When sub-components keep old parent-widget name prefix after refactor, flag as minor naming drift for EL consideration
- [Empty params class anti-pattern](feedback_empty_params_class_pattern.md) — Empty `class XxxUseCaseParams {}` is a should-fix; use `UseCase<ReturnValue>` with void default instead
- [Text-link button h-11 exception](feedback_button_h11_exception.md) — `h-11` does not apply to text-link-styled `<button>` elements; only to form-interactive controls
- [Inline style tab indicator](feedback_inline_style_tab_indicator.md) — Sliding tab indicator via `style` prop + imperative DOM mutation is a Rule 13 violation; use CSS custom props via className
- [Feature imports app layer](feedback_feature_imports_app_layer.md) — `features/**/presentations/**` must never import from `@/app/`; promote shared components to `core/` first (found in LNS-375 buku-besar-viewer)
- [CSS-hidden dual-branch singleton semantics](feedback_css_hidden_dual_branch_singleton.md) — CSS `hidden`/`sm:hidden` dual-layout keeps BOTH branches mounted; sweep the whole diff for ANY duplicated singleton element (`autoFocus`, `aria-live`/`role=status`, unique `id`, `aria-labelledby`), not just the first found (LNS-364: caught autofocus, missed footer aria-live)
- [LNS-371 accounting mutation SWR keys + source/repo coupling](project_lns371_review_learnings.md) — Mutation SWR keys are universally hardcoded in accounting hooks (pre-existing); domain/sources/journal imports params from domain/repositories (pre-existing LNS-369); create-page providers don't need guarantee pattern
- [Presentation imports data/models Blocker](feedback_presentation_imports_data_models.md) — app/ and presentations/ must never import from data/models/; only domain/sources/ has that exemption (found LNS-379 provider)
- [Use-case private method must not return DataState](feedback_usecase_private_method_datastate.md) — private methods throw on failure and return plain types; returning DataState from a private method is a Major violation (found LNS-379)
- [Idempotency-Key belongs in use case, not service layer](feedback_idempotency_key_layer.md) — `crypto.randomUUID()` inside ServiceImpl is a Major violation; key must be generated in UseCase.execute() and threaded through params (found LNS-117)
- [Provider empty-state gap](feedback_provider_empty_state_gap.md) — If provider shellState never emits "empty" but impl checks for it, EmptyBody is dead code; Minor finding (found LNS-376 calk)
- [Dead sub-state components](feedback_dead_substate_components.md) — Engineers scaffold loading/error/incomplete sub-state files then handle states inline in the body, leaving the sub-state files unused (found LNS-347 recommended-price block)
- [Inline style grid-template-columns](feedback_inline_style_grid_columns.md) — inline `style` prop for CSS grid-template-columns is a Rule 13 violation; use a CSS custom prop + Tailwind arbitrary class (found LNS-347 profitability table)
- [Centralize predicate with message helper](feedback_centralize_predicate_with_message_helper.md) — when a shared helper centralizes error-message mapping, check the instanceof/code-matching predicate at call sites was centralized too, not just the message (found LNS-457)
- [LNS-457 review learnings](project_lns457_review_learnings.md) — uncommitted work shows empty in `dev...HEAD` diff (check `git status`); fixed-cost providers importing from features/accounting is established precedent; single-consumer provider state has a real coupling constraint, not just an oversight
- [revalidateSWRKey throws in catch](feedback_revalidate_swr_key_throws_in_catch.md) — SWR mutate() defaults throwOnError:true; unguarded await inside a not-found recovery catch OR after a success toast/close (new LNS-564 variant) can misfire recovery or leak stale error state into the next dialog open
- [SectionCard fetch-error convention](project_sectioncard_fetch_error_convention.md) — established pattern is text-error-* + ExclamationCircleIcon + retry button; text-warning-* + ExclamationTriangleIcon + no retry is a convention deviation (found LNS-489, Minor)
- [LNS-564 tiered-pricing review learnings](project_lns564_review_learnings.md) — new `domain/helpers/` precedent (pure calc, no violation but novel taxonomy); absent-vs-empty nullable-aggregate done right; exemplary money/quantity test rigor; one Major (revalidate ordering in two new dialogs)
- [LNS-570 review learnings](project_lns570_review_learnings.md) — I/O-orchestrating app-utils correctly disqualified from `domain/helpers/` (side effects + presentation-typed param, not just "takes an entity"); sweep twin implementation-components sharing one display component for the same unfixed defect shape; getter-derived-from-getter is the canonical drift-proof entity pattern
- [LNS-572 review learnings](project_lns572_review_learnings.md) — sole-writer/sole-reader sentinel idiom confirmed twice (create + detail pages), verify via whole-tree grep not just the doc comment; single-guard boolean flag arg inside a `.map()` isn't an SRP violation on its own; spot-check "wire-identical" claims against the actual HTTP layer instead of trusting the docstring
- [Provider dead context values](feedback_provider_dead_context_values.md) — provider exposes onRetry/shellState/isLoadingPage but view never wires them; grep view files for every context-type field, cross-check sibling views (found LNS-640)
